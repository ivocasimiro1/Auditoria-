Instalação Gratuita

GitHub + Cloudflare Pages + Supabase — tudo gratuito, sem prazo de validade. As lojas criam as próprias passwords.

Passo 1 de 6

🐙 Criar conta no GitHub

O GitHub é onde o código fica guardado na nuvem. É de graça para sempre no plano gratuito.

github.com → Sign up
  • Usa o email ivocasimiro@gmail.com
  • Confirma o email que receberes
  • O repositório Auditoria- já existe — não precisas criar um novo
✓ Já tens conta GitHub (repositório ivocasimiro1/Auditoria-) — podes saltar este passo!
Passo 2 de 6

☁️ Ligar ao Cloudflare Pages

O Cloudflare Pages publica o site automaticamente sempre que fizeres alterações. Também gratuito.

pages.cloudflare.com → Log in
  • Clica em "Create application" → "Pages"
  • Escolhe "Connect to Git" → GitHub
  • Seleciona o repositório Auditoria-
  • Framework preset: None (deploy direto)
  • Clica "Save and Deploy"
✓ O teu site auditoria-25b.pages.dev já está no Cloudflare — a página /depositos já está publicada!
Passo 3 de 6

🗄️ Configurar Supabase (base de dados)

O Supabase guarda os dados de todas as lojas na nuvem e gere os logins.

supabase.com → Sign in with GitHub
  • Abre o projeto ubeqidccuvsjhjphybxz (já existe)
  • Vai a SQL Editor
  • Copia e cola o conteúdo do ficheiro sql/depositos_setup.sql
  • Clica Run — cria as 3 tabelas e as regras de segurança
✓ Basta executar o SQL uma vez — já fica tudo configurado automaticamente.
Passo 4 de 6

👤 Criar utilizadores no Supabase

Cada loja e o Ivo precisam de um utilizador criado no painel do Supabase.

supabase.com → Authentication → Users → Add user
  • Clica "Add user" → "Create new user"
  • Preenche email (ex: bblago@despomar.com) e password inicial
  • Copia o UUID que aparece ao lado do utilizador criado
  • No SQL Editor, executa:
    INSERT INTO dep_users (id, store_id, role, nome) VALUES
    ('<UUID-BB-LAGOS>', 'bb-lagos', 'staff', 'Responsável BB Lagos'),
    ('<UUID-ESS-FARO>', 'ess-faro', 'staff', 'Responsável ESS Faro'),
    ('<UUID-IVO>', 'super', 'super_admin', 'Ivo Casimiro');
⚠️ O store_id do Ivo deve ser 'super' e role 'super_admin' — assim vê todas as lojas.
Passo 5 de 6

🏪 Configurar cada loja (1ª entrada)

Na primeira vez que cada loja entra, configura o nome, email e responsáveis nas Configurações.

  • Acede a auditoria-25b.pages.dev/depositos
  • Entra com o email e password da loja
  • Vai ao separador ⚙️ Configurações
  • Preenche: Nome da empresa, Email contabilidade, Lojas, Responsáveis
  • Clica "✓ Guardar Configurações"
✓ As configurações ficam guardadas na nuvem e aparecem em todos os dispositivos desta loja.
Passo 6 de 6 — Lojas

🔑 Como a loja recupera a password?

Se uma loja esquecer a password, é simples — ela própria recupera sem precisar de chamar ninguém.

  • Acede a /depositos
  • Clica em "Esqueceu a password?"
  • Introduz o email da loja
  • Recebe email automático do Supabase com link
  • Clica no link → cria nova password
✓ O link de recuperação redireciona para o endereço correto automaticamente. Cada loja é autónoma.

O maior obstáculo de uma pequena escola de surf adoptar tecnologia? O custo fixo. A mensalidade que tens de pagar mesmo quando o verão termina. O contrato que te prende quando a época é fraca. O software caro que tens de aprender a usar. Por isso construí um modelo diferente: → Zero custos fixos → Comissão de 3% só quando a aula acontece → Sem mensalidades. Sem contratos. Se a escola não vende, não paga nada. Este é o tipo de alinhamento de interesses que faz sentido — quem fornece o serviço ganha quando o cliente ganha. Vi este modelo a funcionar no retalho.

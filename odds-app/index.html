Deteção de arbitragem (surebets) e value bets — Grupo Despomar

⚠️ Ferramenta de análise, não conselho financeiro. Apostar com arbitragem/value betting é legal na maioria das jurisdições, mas as casas de apostas ativamente detetam e podem limitar ou banir contas que o façam de forma consistente. Os dados dependem da disponibilidade e latência do fornecedor (The Odds API) — confirma sempre as odds na própria casa antes de apostar.
Edge/Lucro mín. só filtram as listas completas abaixo — a "Sugestão principal" mostra sempre a melhor oportunidade encontrada, seja qual for o valor nestes campos.
Corre 1ªs e 2ªs divisões principais, FIFA/UEFA, NBA e EuroLeague de uma vez (~22 pedidos à API) e junta tudo numa lista só, ordenada por confiança. Usa os mesmos filtros (Edge/Lucro/Casas) de cima. Automático a cada 2 dias ao abrir a página; toca no botão para forçar antes disso.

Arbitragem 0

O que é: apostar em todos os resultados possíveis do jogo, cada um numa casa diferente, de forma a ganhar dinheiro seja qual for o resultado. Só é possível porque as casas discordam o suficiente entre si sobre as probabilidades.
% no topo do card — lucro garantido sobre o total apostado (ex: +0.8% = apostas 100€ no total, ganhas 100.80€ sempre, independentemente do resultado).
Stake % — que fatia desse total apostar em cada perna, para o lucro ser igual seja qual for o resultado.
Confiança — combina 3 sinais: quantas casas a API tinha para este jogo (mais = dados mais fiáveis), se o valor está numa faixa "normal" e não suspeita, e se o jogo é em breve (odds mais assentes). Não é garantia — é só uma bússola para saberes onde vale mais a pena olhar primeiro.

Value bets 0

O que é: uma casa está a oferecer uma odd mais alta do que a probabilidade real do evento sugere — não é lucro garantido (podes perder essa aposta), mas é uma vantagem matemática que compensa a longo prazo, ao longo de muitas apostas.
Odd oferecida — a odd que essa casa está a dar (todas por defeito; usa o campo "Casas" acima para restringir só às que tens conta, ex: bwin, Betclic).
Odd justa (consenso) — a odd que "deveria" ser, calculada pela média de várias casas sem a margem de lucro de cada uma. Quanto mais alta a odd oferecida for face a esta, maior a vantagem.
% no topo do card (edge) — vantagem esperada por unidade apostada, a longo prazo (ex: +8% = em média, por cada 100€ apostados em situações destas, esperas ganhar 8€ a mais do que o "justo" — mas em cada aposta individual podes perder na mesma).
Confiança — combina quantas casas confirmam a odd justa, se o edge está numa faixa normal (nem marginal nem suspeito) e se o jogo é em breve. Ajuda a priorizar, não é garantia de nada.
Stake sugerido (¼ Kelly) — quanto apostar da tua Banca (campo acima) nesta aposta específica, segundo o critério de Kelly fracionário (¼, mais conservador) — dimensiona o risco à vantagem matemática, sem arriscar a banca toda numa só aposta.

Value bets do modelo próprio 0

O que é: em vez de comparar as casas entre si (o que só encontra valor quando as casas discordam umas das outras), compara a odd de cada casa contra a nossa própria previsão (histórico de golos, mesma base da secção Previsões). Encontra oportunidades que a secção "Value bets" acima nunca conseguiria ver — quando todas as casas concordam entre si, mas o nosso modelo, com dados históricos, discorda de todas ao mesmo tempo.
Odd do modelo — a odd "justa" segundo a nossa própria estimativa (não o consenso de outras casas).
Só cobre as ligas onde há previsão disponível (ver secção Previsões abaixo) — jogos fora disso não aparecem aqui. Tal como os value bets normais, não é lucro garantido.

Previsões (modelo estatístico) 0

O que é: uma estimativa própria da probabilidade de cada resultado, calculada a partir do histórico de golos marcados/sofridos por cada equipa esta época (dados públicos do football-data.co.uk) — não depende de nenhuma casa de apostas, por isso aparece mesmo quando não há nenhuma discrepância entre bookmakers a explorar.
Golos esperados — quantos golos o modelo espera de cada equipa, dado o seu ataque e a defesa do adversário.
Cobre só as principais ligas europeias (Premier League, La Liga, Serie A, Bundesliga, Ligue 1, Primeira Liga) e só equipas cujo nome foi reconhecido nos dados históricos — jogos fora disso simplesmente não aparecem aqui. É um modelo simplificado (versão mais simples do que o motor Dixon-Coles completo do projeto EdgeBet), pensado para apontar uma direção, não para prever resultados com certeza.
